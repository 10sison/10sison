## ✨ The Vibe

High-contrast, sticker-pack energy — bold condensed type, halftone dot textures, and a hot-pink-on-black-and-white palette that swaps freely between backgrounds. Think collectible, stackable, a little glitchy. If it doesn't pop off the page, it doesn't ship.
